# Créditos e condições de terceiros

O código próprio é disponibilizado sob a [licença MIT](LICENSE). O projeto foi desenvolvido inicialmente na RioCode e reutilizado com autorização para a versão pessoal de Moscarde. A licença do software não altera as condições das fontes de dados ou dos ativos de terceiros.

| Material | Origem e condições |
|---|---|
| Dados de internações | SIH/SUS — DATASUS. Manter fonte, recorte e limitações; não atribuir a licença MIT do código aos dados oficiais. Ver [metodologia](docs/metodologia.md). |
| Referência cadastral hospitalar | Tabela `DBF/TCNESRJ.dbf`, arquivo oficial `TAB_SIH.zip`; data e hash no manifest. Não é uma reconstrução histórica. |
| Geografia | [geodata-br](https://github.com/tbrugz/geodata-br), malha histórica atribuída ao IBGE e distribuída sob CC0. Versão territorial não informada pelo distribuidor. |
| Gráficos do painel | [Apache ECharts](https://github.com/apache/echarts), Apache-2.0. A distribuição oficial instalada via npm inclui LICENSE e NOTICE. |
| Interface | React, MIT; Tailwind CSS, MIT. Licenças presentes nas respectivas distribuições npm. |
| Tipografia local | IBM Plex, SIL Open Font License 1.1. Texto preservado em `frontend/public/fonts/OFL.txt`. |
| Fotos do Rio de Janeiro | Wilfredor, Wikimedia Commons, CC0: [Botafogo](https://commons.wikimedia.org/wiki/File:Rio_de_Janeiro_coastal_skyline_at_sunset,_Brazil.jpg) e [montanhas](https://commons.wikimedia.org/wiki/File:Aerial_view_of_Rio_de_Janeiro_and_its_mountains,_Brazil.jpg). |
| Ilustração anatômica | Gray's Anatomy, 1918, [domínio público](https://commons.wikimedia.org/wiki/File:Gray516.png). |

Parquet, bancos locais, relatórios e screenshots gerados mantêm a atribuição às respectivas fontes. Os agregados publicados não contêm identificadores de AIH. Fixtures sintéticas permanecem exclusivamente nos testes.
